# Portifolio
Portifolio for CS3365

Portifolio is my website created for a class to be used for employers to look at to get an idea of who they are hiring. The website contains a short about me to get an idea of my interest in computer science and links to my social media sites. The website also contains a list of all projects I've worked on and a link to my coverletter which is holding my temp cover letter.

Used visual Studios and the command terminal and the site is written in the HTML

https://Fern-or-Nando.github.io/Portifolio/

Run the following to get to site
git clone https://github.com/Fern-or-Nando/Portifolio.git
cd Portifolio
start index.html
